# My first page | FF: Fleet Foxes

Welcome to **FFabout**: an immersive fan-page dedicated to the band Fleet Foxes.  
Here you’ll explore their history, music, visuals and influence — all wrapped in a clean, responsive web experience.

This project is a practice of the skills obtained from the Front-End Development Bootcamp 2024 by Technolochicas PRO.

---

## 🎶 About...

FFabout is a curated online space where fans and newcomers alike can dive into the atmospheric world of Fleet Foxes — from their lush vocal harmonies to their rich folk-rock soundscapes. It’s designed to be both informative and visually engaging, honouring the band’s aesthetic and musical journey.

* HTML
* CSS
* Bootstrap
* Javascript
* Hosted and deployed via Netlify
